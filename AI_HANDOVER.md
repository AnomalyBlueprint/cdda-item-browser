## Project Overview
This project is the **CDDA Item & Sprite Browser**, a fast, static web application designed to track tileset and sprite completion for Cataclysm: Dark Days Ahead. It allows users to quickly verify which sprites are missing across the 11 official tilesets. 

To solve bandwidth and performance issues, this project intentionally avoids loading the 35,000+ raw JSON files from the game. Instead, it relies on a custom Python script that flattens and extracts only essential rendering metadata into a highly optimized, lightweight payload.

## Current State & Achievements
1. **Isolated Workspace:** The project has been successfully migrated out of the massive CDDA source tree into this clean, standalone repository.
2. **Lightweight Extraction:** We created `build_light_defs.py` to strip away heavy RPG combat stats and extract only rendering metadata (ID, Name, Symbol, Color, Mod), reducing the JSON size from ~4.5MB down to ~1MB.
   *(Note: The old, heavy RPG extraction logic is backed up in `build_rpg_stats_offline.py` for future offline-engine use, but is completely ignored by this web version).*
3. **Multi-Version UI:** We implemented a "Version" dropdown in `ItemBrowser.html`. The frontend dynamically reads `versions.json` and hot-swaps the `items_defs.json` and `gfx/` asset paths to allow viewing historical or experimental datasets.
4. **Repository Prep:** `.gitignore`, `README.md`, and a CC-BY-SA 3.0 `LICENSE` are in place.

## Architecture Guidelines
- **Main Branch:** Must remain tiny. It should only contain the HTML, Python scripts, JSON index, and repository configs.
- **Data & Assets:** `items_defs.json`, `sprite_index.json`, and the `gfx/` folders are heavily ignored in `.gitignore`. They are meant to be generated by a cloud CI/CD pipeline and deployed directly to a `gh-pages` branch.
- **No Forking:** Do **NOT** fork the official CDDA repository. This repository must remain independent to prevent bloating.
